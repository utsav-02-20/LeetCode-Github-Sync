LeetSync Workflow Guide

Automate your developer portfolio by syncing your accepted LeetCode solutions directly to GitHub.

End-to-End How It Works

1. Connect GitHub Account
Authenticate using GitHub OAuth or Personal Access Token (PAT) with repo scope.
2. Configure Target Repository
Select target repository name, branch, folder structure (Topic, Difficulty, Language, or Flat), and commit template.
3. Solve Problems on LeetCode
When a submission receives an Accepted verdict, LeetSync automatically captures the code, runtime, memory, and difficulty.
4. Instant GitHub Sync & README Update
Your solution is committed to GitHub, updating `README.md` progress shields automatically.
5. Track Progress & Backups
Monitor sync stats, day streaks, and sync history in the Popup Dashboard or run full batch backups.
