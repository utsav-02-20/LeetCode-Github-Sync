LeetSync Workflow

This page explains how the extension works end-to-end, and gives quick access to setup.

How It Works

1. Connect GitHub
Login from Settings using either OAuth or PAT.
2. Configure Repository
Set repository name, branch, and sync preferences.
3. Solve on LeetCode
When a submission is accepted, LeetSync captures it.
4. Auto Sync to GitHub
Your solution is created/appended in the configured repo.
5. Track Progress
Use Popup and Settings Analytics/History tabs to monitor sync status.
